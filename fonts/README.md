# Fonts

`DroidSans.woff2` and `DroidSans-Bold.woff2` are Droid Sans, the Android
2.x system font, from the Android Open Source Project
(`platform/frameworks/base`, branch `gingerbread`, `data/fonts/`).
They are subset to Latin and General Punctuation and converted to WOFF2;
the glyphs are unchanged.
