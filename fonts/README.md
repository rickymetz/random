# Fonts

`DroidSans.woff2` and `DroidSans-Bold.woff2` are Droid Sans, the Android
2.x system font, from the Android Open Source Project
(`platform/frameworks/base`, branch `gingerbread`, `data/fonts/`).
They are subset to Latin and General Punctuation and converted to WOFF2;
the glyphs are unchanged.

Copyright (c) 2005-2008, The Android Open Source Project. Licensed under
the Apache License, Version 2.0 — see `LICENSE-DroidSans.txt`.

Droid Sans is used only by the hub's retro (Gingerbread) look.

`Archivo-Heavy.woff2` is Archivo by the Archivo Project Authors
(Omnibus-Type), from the Fontsource latin subset of the variable font,
instanced with fontTools to width 112 and weights 700–900. Licensed under
the SIL Open Font License 1.1 — see `LICENSE-Archivo.txt`. Used by the
hub's modern look for headlines.
