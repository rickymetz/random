# Ephemera Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `ideas/ephemera/` — a static browser for the ~8,038 titled ephemeral films in Internet Archive's Prelinger collection, watchable in-page.

**Architecture:** Same shape as its sibling `ideas/public-screening/`: an author-time Node scraper writes a committed `data.json`, a single self-contained `index.html` does all searching/filtering/sorting/playback client-side, and a second author-time script generates per-item static share pages for social unfurls. Unlike Public Screening, there is exactly one upstream source (archive.org) and each item arrives with a stable identifier, so there is no title-matching step and none of that app's matching-related failure modes apply.

**Tech Stack:** Vanilla HTML/CSS/JS, no framework, no build step, no runtime dependencies. Node (bare, no `package.json`, no npm deps) for the two author-time scripts. Playwright for verification.

## Global Constraints

- **No dependencies, no build step.** Every idea in this hub is plain HTML/CSS/JS that works when opened directly. Do not add `package.json`, npm packages, bundlers, or frameworks. (`README.md` "Conventions")
- **Relative URLs only** — the site is served under `/random/`, so absolute paths like `/foo.png` break.
- **Author-time scripts never run in CI.** `.github/workflows/pages.yml` runs only `scripts/build.js`. Both `build-data.mjs` and `build-share-pages.mjs` are run by hand.
- **Source of truth for all data: `https://archive.org`.** No other upstream.
- **Collection query (exact):** `collection:prelinger AND NOT title:(Home Movie)`
- **Item count:** drifts as the collection grows. Design-time measurement saw 8,046 results → 8,039 films; the actual Task 1 run saw 8,045 → **8,038**. Never hardcode a count in a verification regex — match `80\d\d`. User-facing copy should use the count in the built `data.json`, not a number from this plan.
- **Year ceiling: 2015.** Any resolved year above this is a digitization/upload timestamp, not a film date — discard it.
- **Junk subject tags to drop (case-insensitive):** `need keyword`, `need meta`, `to come`, `needs keyword`, `tbd`
- **Tag chip frequency threshold: 40** (yields 41 chips).
- **Description cap in `data.json`: 400 characters**, ellipsised on a word boundary. Full description is fetched client-side on demand.
- **Verification is Playwright against a local server.** There is no test runner in this repo and adding one would violate the no-dependencies rule. Serve with `python3 -m http.server 6085 --bind 127.0.0.1` from the repo root; the app is at `http://127.0.0.1:6085/ideas/ephemera/`.
- **Test both Chromium and Firefox.** This repo has a documented history of engine-specific rendering differences.
- **Commit after every task.** End commit messages with `Claude-Session: https://claude.ai/code/session_01AJJUtkzYtNYG8qXffxw4om`.

```json
  "scraped": "2026-08-31",
  "count": 8039,

```
Field keys are short because they repeat 8,039 times: `id` identifier, `t` title, `sort` sort-key, `y` year, `d` description, `g` tag slugs, `n` downloads. `y`, `d`, `g`, `n` are omitted when absent — never null.

Create `ideas/ephemera/build-data.mjs`:

```js
#!/usr/bin/env node
// Author-time scraper for Ephemera. NOT part of CI — the hub workflow only
// runs scripts/build.js. Run by hand to refresh data.json:
//
//   node ideas/ephemera/build-data.mjs
//
// One source: archive.org. Every item arrives with a stable identifier, so
// unlike the sibling public-screening app there is no title matching here
// and none of its matching failure modes apply.
import fs from "node:fs";
import path from "node:path";

const UA = "random-hub/1.0 (+https://github.com/rickymetz/random) static catalog browser";
const QUERY = "collection:prelinger AND NOT title:(Home Movie)";
const SOURCE = "https://archive.org/details/prelinger";
const outFile = path.join(import.meta.dirname, "data.json");

// Archivist placeholders, not topics. "need keyword" is the second most
// common tag in the entire collection — 225 items — so this matters.
const JUNK = new Set(["need keyword", "need meta", "to come", "needs keyword", "tbd"]);
// Decade-shaped tags belong to the decade filter, not the topic chip rail.
const DECADE_TAG = /^(1[89]\d0s|20\d0s)$/i;
// Above this, a "year" is a digitization timestamp rather than a film date.
// 137 items claim the 2020s. public-screening shipped this bug once already.
const MAX_YEAR = 2015;
const MIN_YEAR = 1890;
const TAG_THRESHOLD = 40;
const DESC_CAP = 400;

const scrapeUrl = (cursor) => {
  const p = new URLSearchParams({
    q: QUERY,
    fields: "identifier,mediatype,title,year,date,subject,description,downloads",
    count: "10000",
  });
  if (cursor) p.set("cursor", cursor);
  return `https://archive.org/services/search/v1/scrape?${p}`;
};

async function scrapeAll() {
  const items = [];
  let cursor = null, page = 0;
  do {
    const res = await fetch(scrapeUrl(cursor), { headers: { "User-Agent": UA } });
    if (!res.ok) throw new Error(`scrape HTTP ${res.status}`);
    const body = await res.json();
    items.push(...(body.items || []));
    cursor = body.cursor || null;
    console.log(`  page ${++page}: ${items.length}/${body.total}`);
  } while (cursor);
  return items;
}

const clean = (s) => String(s ?? "").replace(/<[^>]+>/g, " ").replace(/\s+/g, " ").trim();

function subjects(raw) {
  let s = raw.subject || [];
  if (typeof s === "string") s = [s];
  return s.map((t) => String(t).trim()).filter(Boolean);
}

function resolveYear(raw) {
  for (const field of [raw.year, raw.date]) {
    if (!field) continue;
    const m = String(field).match(/(1[89]\d\d|20\d\d)/);
    if (m) {
      const y = parseInt(m[1], 10);
      if (y >= MIN_YEAR && y <= MAX_YEAR) return y;
    }
  }
  return null;
}

// "A Trip Down Market Street" sorts under T, matching the sibling app.
const sortTitle = (t) => t.replace(/^(a|an|the)\s+/i, "").toLowerCase();

const raw = await scrapeAll();
const movies = raw.filter((r) => r.mediatype === "movies");
console.log(`${movies.length} movies (dropped ${raw.length - movies.length} non-film collection entries)`);

// Build the chip vocabulary first: count case-folded, display the most
// common original casing ("FOOD" and "Food" are the same tag).
const freq = new Map(), casing = new Map();
for (const r of movies) {
  for (const t of subjects(r)) {
    const k = t.toLowerCase();
    if (JUNK.has(k) || DECADE_TAG.test(k)) continue;
    freq.set(k, (freq.get(k) || 0) + 1);
    if (!casing.has(k)) casing.set(k, new Map());
    const c = casing.get(k);
    c.set(t, (c.get(t) || 0) + 1);
  }
}
const tags = [...freq.entries()]
  .filter(([, n]) => n >= TAG_THRESHOLD)
  .sort((a, b) => b[1] - a[1])
  .map(([slug, n]) => {
    const best = [...casing.get(slug).entries()].sort((a, b) => b[1] - a[1])[0][0];
    return { slug, label: best, n };
  });
const keep = new Set(tags.map((t) => t.slug));
console.log(`${tags.length} tag chips at >=${TAG_THRESHOLD} items`);

const items = movies.map((r) => {
  const rec = { id: r.identifier, t: clean(r.title) || r.identifier };
  rec.sort = sortTitle(rec.t);
  const y = resolveYear(r);
  if (y) rec.y = y;
  let d = clean(r.description);
  if (d.length > DESC_CAP) d = d.slice(0, DESC_CAP).replace(/\s+\S*$/, "") + "…";
  if (d) rec.d = d;
  const g = [...new Set(subjects(r).map((t) => t.toLowerCase()).filter((t) => keep.has(t)))].sort();
  if (g.length) rec.g = g;
  if (r.downloads != null) rec.n = r.downloads;   // a real 0 is present, not absent
  return rec;
}).sort((a, b) => a.sort.localeCompare(b.sort));

// Refuse to replace a good dataset with a bad run. The sibling app learned
// this the hard way: a partial scrape silently gutted data.json.
if (fs.existsSync(outFile)) {
  const prev = JSON.parse(fs.readFileSync(outFile, "utf8"));
  if (items.length < prev.count * 0.8 && !process.argv.includes("--force")) {
    console.error(`refusing to write: ${items.length} items vs ${prev.count} previously (>20% loss)`);
    console.error("re-run with --force if this is intentional");
    process.exit(1);
  }
}

fs.writeFileSync(outFile, JSON.stringify({
  source: SOURCE,
  query: QUERY,
  scraped: new Date().toISOString().slice(0, 10),
  count: items.length,
  tags,
  items,
}));
const kb = Math.round(fs.statSync(outFile).size / 1024);
console.log(`wrote data.json: ${items.length} items, ${tags.length} tags, ${kb} KB`);
console.log(`  with year: ${items.filter((i) => i.y).length}`);
console.log(`  with description: ${items.filter((i) => i.d).length}`);
console.log(`  with >=1 chip tag: ${items.filter((i) => i.g).length}`);
```

```js
"use strict";
const $ = (id) => document.getElementById(id);
const esc = (s) => String(s).replace(/[&<>"']/g, (c) =>
  ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" }[c]));
const IA = "https://archive.org";
const grid = $("grid"), countEl = $("count"), empty = $("empty");

let ALL = [], TAGS = [], shown = [], drawn = 0;
const PAGE = 120;
const state = { q: "", tags: new Set(), decade: "", sort: "-n", view: "grid", favOnly: false };

const SORTS = {
  "-n": (a, b) => (b.n || 0) - (a.n || 0),
  "year": (a, b) => (a.y || 9999) - (b.y || 9999),
  "-year": (a, b) => (b.y || 0) - (a.y || 0),
  "title": (a, b) => a.sort.localeCompare(b.sort),
};

function matches(m) { return true; }   // filters arrive in Tasks 3 and 4

function posterHTML(m) {
  const src = `${IA}/services/img/${encodeURIComponent(m.id)}`;
  return `<div class="poster">` +
    `<div class="gen"><span class="t">${esc(m.t)}</span></div>` +
    `<img src="${esc(src)}" alt="" loading="lazy" decoding="async"
          onerror="this.remove()">` +
    (m.y ? `<span class="badge">${m.y}</span>` : "") +
  `</div>`;
}

function cardHTML(m, i) {
  const sub = [m.y, m.n ? m.n.toLocaleString() + " views" : null].filter(Boolean).join(" · ");
  return `<div class="card-wrap">` +
    `<button class="card" data-i="${i}" aria-label="Open ${esc(m.t)}"></button>` +
    posterHTML(m) +
    `<span class="meta">` +
      `<span class="name">${esc(m.t)}</span>` +
      `<span class="sub">${esc(sub)}</span>` +
    `</span>` +
  `</div>`;
}

function drawMore() {
  if (drawn >= shown.length) return;
  const next = shown.slice(drawn, drawn + PAGE);
  grid.insertAdjacentHTML("beforeend", next.map((m) => cardHTML(m, m._i)).join(""));
  drawn += next.length;
}

function render() {
  shown = ALL.filter(matches).sort(SORTS[state.sort]);
  grid.className = "grid" + (state.view === "list" ? " list" : "");
  grid.innerHTML = "";
  drawn = 0;
  drawMore();
  empty.hidden = shown.length > 0;
  countEl.textContent = `${shown.length} / ${ALL.length}`;
}

new IntersectionObserver((e) => { if (e[0].isIntersecting) drawMore(); })
  .observe($("sentinel"));

$("viewGrid").onclick = () => { state.view = "grid"; render(); };
$("viewList").onclick = () => { state.view = "list"; render(); };

fetch("data.json")
  .then((r) => { if (!r.ok) throw new Error(`HTTP ${r.status}`); return r.json(); })
  .then((data) => {
    ALL = data.items;
    TAGS = data.tags;
    ALL.forEach((m, i) => { m._i = i; });
    render();
  })
  .catch((err) => {
    grid.innerHTML = `<p class="err">Could not load the catalogue (${esc(err.message)}).</p>`;
  });
```

Replace the stub `matches()` and add the state machinery:

```js
function matches(m) {
  if (state.q) {
    const q = state.q.toLowerCase();
    const hay = m._hay || (m._hay = [m.t, m.d || "", (m.g || []).join(" ")].join(" ").toLowerCase());
    if (!hay.includes(q)) return false;
  }
  return true;
}

const isFiltered = () => Boolean(state.q || state.tags.size || state.decade || state.favOnly);

const PREFS = "ephemera:prefs";

function writeUrl(push) {
  const p = new URLSearchParams();
  if (state.q) p.set("q", state.q);
  if (state.sort !== "-n") p.set("sort", state.sort);
  if (state.view !== "grid") p.set("v", state.view);
  const hash = p.toString();
  const url = location.pathname + (hash ? "#" + hash : "");
  if (push && url !== location.pathname + location.hash) history.pushState(null, "", url);
  else history.replaceState(null, "", url);
}

// Always assigns every URL-carried field, returning only whether a hash was
// present. An early return here meant an empty hash assigned nothing, so
// back-navigating onto a bare URL kept the previous search/sort while the
// URL said otherwise. Any filter state added below must follow this pattern.
function readUrl() {
  const p = new URLSearchParams(location.hash.replace(/^#/, ""));
  const had = Boolean(p.toString());
  state.q = p.get("q") || "";
  state.sort = SORTS[p.get("sort")] ? p.get("sort") : "-n";
  state.view = p.get("v") === "list" ? "list" : "grid";
  return had;
}

function savePrefs() {
  try {
    localStorage.setItem(PREFS, JSON.stringify({ sort: state.sort, view: state.view }));
```

```js
//   node ideas/ephemera/build-share-pages.mjs
import fs from "node:fs";
import path from "node:path";

const root = import.meta.dirname;
const outDir = path.join(root, "f");
const SITE = "https://rickymetz.github.io/random/ideas/ephemera/";
const IA = "https://archive.org";

const esc = (s) => String(s).replace(/[&<>"']/g, (c) =>
  ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" }[c]));
const ldJSON = (o) => JSON.stringify(o).replace(/<\//g, "<\\/");

const data = JSON.parse(fs.readFileSync(path.join(root, "data.json"), "utf8"));

function page(m) {
  const title = m.y ? `${m.t} (${m.y})` : m.t;
  const desc = m.d || `${title} — an ephemeral film from the Prelinger Archives, free to watch on Ephemera.`;
  const image = `${IA}/services/img/${encodeURIComponent(m.id)}`;
  const url = `${SITE}f/${encodeURIComponent(m.id)}/`;
  const dest = `../../#item=${encodeURIComponent(m.id)}`;
  const destAbs = `${SITE}#item=${encodeURIComponent(m.id)}`;

  const ld = {
    "@context": "https://schema.org", "@type": "Movie",
    name: title, url: destAbs, image, description: desc,
  };
  if (m.y) ld.datePublished = String(m.y);
  if (m.g?.length) {
    ld.genre = m.g.map((g) => (data.tags.find((t) => t.slug === g) || {}).label || g);
  }

  return `<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<title>${esc(title)} — Ephemera</title>
<meta name="robots" content="noindex">
<link rel="canonical" href="${esc(destAbs)}">
<meta property="og:type" content="video.movie">
<meta property="og:site_name" content="Ephemera">
<meta property="og:title" content="${esc(title)}">
<meta property="og:description" content="${esc(desc)}">
<meta property="og:url" content="${esc(url)}">
<meta property="og:image" content="${esc(image)}">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="${esc(title)}">
<meta name="twitter:description" content="${esc(desc)}">
<meta name="twitter:image" content="${esc(image)}">
<meta http-equiv="refresh" content="0; url=${esc(dest)}">
<script type="application/ld+json">${ldJSON(ld)}</script>
<style>
  body { background:#15191b; color:#8b9aa0; font:15px/1.6 system-ui,sans-serif;
         display:grid; place-items:center; height:100vh; margin:0; text-align:center }
  a { color:#5fb3a1 }
</style>
</head>
<body>
  <p>Opening <a href="${esc(dest)}">${esc(title)}</a> on Ephemera.</p>
<script>location.replace(${JSON.stringify(dest)});</script>
</body>
</html>
`;
}

fs.rmSync(outDir, { recursive: true, force: true });
fs.mkdirSync(outDir, { recursive: true });
let n = 0;
for (const m of data.items) {
  // Identifiers come from Archive and are [A-Za-z0-9._-]; verify before
  // using one as a directory name.
  // A dot is legal in an Archive identifier, so the character-class test
  // alone accepts "." and ".." -- and path.join(outDir, "..") resolves above
  // f/, where writing index.html would clobber the app itself. Reject
  // all-dot ids explicitly.
  if (!/^[A-Za-z0-9._-]+$/.test(m.id) || /^\.+$/.test(m.id)) {
    console.warn(`  skipping unsafe identifier: ${m.id}`);
    continue;
  }
  const dir = path.join(outDir, m.id);
  fs.mkdirSync(dir, { recursive: true });
  fs.writeFileSync(path.join(dir, "index.html"), page(m));
  n++;
}
console.log(`wrote ${n} share pages to f/`);
```

## Self-review notes

**Spec coverage** — every spec section maps to a task: data pipeline → 1; scope/exclusions → 1 (mediatype filter, `NOT title:(Home Movie)` in the query); tag chips → 4; browsing/search/sort → 3, 4; playback & detail → 5; favorites → 6; share pages → 7; visual identity → 2 (teal accent, 4:3 poster); naming → 2 (`idea.json`); honest coverage disclosure → 8.

**Deliberate deviation from the spec**, decided during planning and recorded here: the spec assumed a per-item `metadata/<id>` call at scrape time to collect runtime. Measurement showed that is 8,039 sequential polite requests (hours) for a field the spec had already dropped as a filter. Archive's metadata API sends `access-control-allow-origin: *`, so Task 5 fetches runtime and the full description in the browser for the one item actually opened. This also caps `data.json` at ~690 KB gzipped instead of 4.4 MB.

**Known non-goals for v1**, carried from the spec: raw home movies, preset chip rails, ratings.
