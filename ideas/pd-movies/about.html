This page is an index of films. It does not contain films. It lists the films from a different website, and lets you search, filter and sort that list.

Other people made all of the data on this page. This section gives the credit to them.

The catalogue

Public Domain TorrentsSource

This page reads all of the titles, the genres, the formats and the star ratings from their website. They collect and supply public domain films. They started this work in the early 2000s.

The program reads their website one page at a time. It waits 1.5 seconds between each page. It sends a User-Agent that identifies it. It also keeps a copy of each page. Thus a second run does not add load to their server.

Their website has the downloads, the plot summaries and the user comments. This page does not have them. Use their website to get a film.

Years and artwork

The source website does not give a release year. It does not give poster art. This page gets these two items from three other databases.

TheTVDBArtwork and years

TheTVDB supplies metadata and artwork. It gives more posters to this page than the other two sources.

Volunteers make TheTVDB. They add and correct each entry manually. If a film is not correct, you can add the correct data. You can also subscribe to give support to the project.

fanart.tvArtwork

fanart.tv supplies more poster artwork. A community of users collects and approves this artwork for films and television.

Wikidata and Wikimedia CommonsYears and artwork

Most of the release years come from Wikidata. Wikidata supplies its data under the CC0 licence.

If TheTVDB and fanart.tv do not have a poster, the image comes from Wikimedia Commons. Each Commons file has its own licence and its own author credit. The page for the file shows this information.

How the page matches a film

The source website gives only a title. It does not give a year. It does not give an IMDb identifier. Thus this page matches each film to the databases by the title only. Two rules make the matches more accurate.

  • The title must be an exact match. First the program makes the letter case, the spaces and the punctuation the same in both titles. Without this rule, a database search can return a different film. A wrong result of this type looks the same as a correct result.
  • The program refuses a date after 1990. The most recent films in this catalogue are from the late 1980s. Thus a more recent match shows that the database does not have the correct film. The match is a different film with the same name.

These two rules are not sufficient. A remake from the same period can obey both rules. Thus some years and some posters on this page are for the wrong film.

If the program does not find a good match, the film shows no year. The page then draws a poster from the title of the film. An empty field is better than incorrect data.

Limits of this page

  • No plot summaries. The summaries belong to the source website. This page does not copy them.
  • No download links. Each film links to its page on Public Domain Torrents. The files stay on their website.
  • No screenshots from their server.
  • No tracking, no analytics and no cookies. This page is one HTML file and one data file.

The status of the films

The source website lists these films as public domain in the United States. Usually the copyright expired, or the owner did not renew it.

Public domain status is different in each country. For some films the status is not certain. This list shows the opinion of the source website. It is not legal advice.

How to correct an error

You can correct a wrong poster, a wrong year or a missing film. Make the correction at the source:

  • Film data: TheTVDB or Wikidata
  • Artwork: fanart.tv
  • The catalogue: Public Domain Torrents

The next run of the program includes your correction.
